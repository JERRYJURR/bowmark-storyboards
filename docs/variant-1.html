Questions we always get.

Is this a crawler or a scraper?

No. Providers are integrated capabilities, not scraped pages — every call runs against a maintained integration with a typed contract, whether the surface behind it is a website flow, an MCP server, an API, or a CLI.

Which agents does it work in?

ChatGPT, Claude, Claude Code, Codex, Cursor, and anything that speaks MCP. Or import it directly from npm or pip.

What does it cost?

Free to start, then metered. That's the whole pricing story — no tiers.

Does it use up my tokens?

Barely — that's the point. A typical call costs 20–50× fewer tokens than the same task done by driving a browser.

What if the site I want isn't covered?

Request the capability from the library and we prioritize by demand. Coverage grows weekly.

Can I use this for my business?

That's Broadcast — we turn your product into a provider and publish it everywhere agents look.
